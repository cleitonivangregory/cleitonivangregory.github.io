# Política de Privacidade - Campo MinaFo

**Última atualização: agosto de 2026**

## 1. Introdução

O aplicativo **Campo MinaFo** é um jogo de Campo Minado desenvolvido com Flutter.

Esta Política de Privacidade descreve como as informações são tratadas durante a utilização do aplicativo.

## 2. Coleta de informações

O Campo MinaFo não coleta, não armazena e não compartilha informações pessoais dos usuários.

O aplicativo não exige:

* cadastro;
* criação de conta;
* login;
* fornecimento de dados pessoais.

O jogo funciona localmente no dispositivo do usuário.

## 3. Armazenamento de dados

O aplicativo pode armazenar informações localmente no dispositivo para manter o funcionamento de recursos do jogo, como preferências ou configurações.

Esses dados permanecem no dispositivo do usuário e não são enviados para servidores externos.

## 4. Compartilhamento de informações

O Campo MinaFo não compartilha, vende ou transfere informações pessoais para terceiros.

## 5. Serviços de terceiros

O aplicativo pode utilizar bibliotecas e tecnologias necessárias para seu funcionamento, porém não utiliza serviços externos para coleta de informações pessoais.

## 6. Segurança

Como o aplicativo não coleta dados pessoais, não existe armazenamento externo dessas informações.

Recomendamos que o usuário mantenha seu dispositivo protegido utilizando os recursos de segurança disponíveis no próprio sistema operacional.

## 7. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada futuramente para refletir melhorias no aplicativo ou alterações em seus recursos.

Recomendamos consultar esta página periodicamente para acompanhar eventuais mudanças.

## 8. Contato

Caso tenha dúvidas sobre esta Política de Privacidade ou sobre o aplicativo Campo MinaFo, entre em contato pelo canal disponibilizado na página do aplicativo.
